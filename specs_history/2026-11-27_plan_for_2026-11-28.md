# Plan for 2026-11-28: deploy, demo, next steps

_Written 2026-11-27._

On 2026-11-28 we move the AxrflowsQuotes backend to the Oracle free server, because Railway only allows email sending on its Pro plan (about $20 a month). Then we record a demo for UAE fabrication workshops and start reaching out to pilot customers.

## 1. Before recording

The demo is recorded against the live app, so the server move and the demo workspace come first. The scripts are already on `master` in `deploy/oracle/` (commit c16c568).

### 1.1 Oracle server (about 1 hour)

- [ ] Create an Oracle Cloud Always Free VM: Ubuntu, Ampere A1 (ARM). Save the SSH key.
- [ ] In the VM's subnet Security List, allow incoming TCP 80 and 443.
- [ ] Get a free DuckDNS hostname (e.g. `axrflows.duckdns.org`) and point it at the VM's public IP.
- [ ] SSH in, download and run `deploy/oracle/setup.sh`, then log out and back in.
- [ ] Copy the Railway variables into `/opt/axrflows/backend/.env.production`. Set `PUBLIC_BACKEND_URL=https://<duckdns host>` and `FRONTEND_URL=https://axrflowsquotes.vercel.app`.
- [ ] Put the hostname in `deploy/oracle/.env` and run `deploy.sh`. Check that `https://<host>/health` responds.

### 1.2 Point everything at the new backend

- [ ] Vercel: set `VITE_BACKEND_URL` to the new URL and redeploy.
- [ ] Add the new backend URL to the CSP in `frontend/vercel.json` (connect-src), then commit.
- [ ] Twilio sandbox: change the WhatsApp webhook to `https://<host>/api/whatsapp/webhook`.
- [ ] Google / Microsoft sign-in: register the new redirect URIs `<host>/api/oauth/google/callback` and `<host>/api/oauth/microsoft/callback`.
- [ ] Send a test quote by email: this is the SMTP check that Railway Hobby blocked.
- [ ] Once everything works, stop the Railway service.

### 1.3 Database and the demo workspace

- [ ] Fix the Woodcorp settings: the industry says packaging but it sells furniture; the signature phone is the Twilio sandbox number; the validity periods don't agree (30, 14 and 7 days); the timezone should be Asia/Karachi. Or create a clean demo company for a UAE aluminium and glass workshop, which matches who we sell to.
- [ ] Load a believable price list (aluminium profiles, glass per m², fabrication and installation labour, in AED) and run 3 to 4 test quotes until the prices come out right.
- [ ] Check the customer quote link and the PDF on a phone (the links now use the live frontend URL).
- [ ] Use a demo mailbox and phone number, not personal ones; hide any API keys or customer data on screen.

### 1.4 Housekeeping (whenever there's time)

## 2. The demo

One story, 3 to 4 minutes: a customer sends a WhatsApp message asking for a price, and a few minutes later they've accepted a priced quote. The viewer is the owner of an aluminium and glass workshop in the UAE who spends evenings pricing jobs by hand.

### Scenes, in order

1. **The problem (15 s).** "Your customers ask for prices on WhatsApp and email at all hours, and every quote is worked out by hand from a price list." Show the price list as an Excel file.
2. **Knowledge base (20 s).** Upload that price list. The app reads it as a table you can edit, and those prices are what it quotes from.
3. **WhatsApp enquiry (40 s).** From a phone, send something like: "Need price for 4 sliding windows 1.5 x 1.2 m, double glazed, installed in Al Quoz." The assistant replies on WhatsApp and the enquiry shows up in the app with a notification.
4. **AI draft quote (45 s).** Open the enquiry: line items, quantities and unit prices taken from the price list, labour, totals and a drafted reply. Point out that anything not in the price list is priced 0 and flagged for a person to check, and that the server recalculates the totals itself.
5. **Review and edit (30 s).** Change one line item, add a discount and VAT at 5%, set the validity date. Then approve.
6. **Send (20 s).** Send by email with the PDF attached, and on WhatsApp with the quote link.
7. **Customer side (30 s).** On the phone, open the quote page and press Accept. Back in the app, the quote shows as accepted.
8. **Email enquiries too (20 s).** An enquiry email arrives in the inbox and the draft quote is created automatically (automation on).
9. **Reports and customers (20 s).** Win rate, value won, time to quote, follow-up flags; a customer's price history.
10. **Close (15 s).** "Live in 48 hours, set up for you: we load your price list and connect your WhatsApp and email." Show the Growth plan ($99/month + $499 setup, setup waived for the first three founding customers) and "Book a 20-minute demo".

**Leave out of the demo:** DXF and STL part upload (hidden in the app for now), the admin portal, the API key and model settings, and sign-up or onboarding screens with empty data.

**Recording tips:** record the screen at 1080p with the phone mirrored beside it, and run the whole scenario once before recording so the AI's answers are already known to be good. Use AED, UAE names and Dubai or Sharjah addresses throughout. Make a 60-second cut of scenes 3, 4, 7 and 10 for WhatsApp status and LinkedIn.

## 3. Next steps

The goal after the demo is three pilot customers among UAE metal, aluminium and glass workshops. We waive the setup fee in return for a case study and their numbers. Work that doesn't help sign or serve those three waits.

### Getting customers (starting right after the demo)

1. Put the demo video on the landing page and in a short WhatsApp and LinkedIn message.
2. Build a list of 50 workshops in Dubai, Sharjah and Ajman (Google Maps, Dubizzle, LinkedIn) and contact 10 a day.
3. Book 20-minute calls and set up each pilot's price list during the call, so they see their own quotes.
4. Contract first, then a Payoneer invoice once a pilot is ready to pay. No payment gateway yet.
